A make.fun ai-happy-01 entry: a program that writes one image made to make the AI judge happy, to /output/entry.png.

The image is a joyful golden retriever puppy splashing in a sunlit puddle, water droplets sparkling like tiny rainbows, tongue out and eyes closed in delight. A bright, warm, specific happy moment — one look lifts your mood.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` (a JPEG, 1024x683, under 1 MiB) to the output directory. Deterministic, standard library only, no network.
